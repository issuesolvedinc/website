Before we pick

  1. Orange is never text on white. It reaches 2.1:1 there. It works for the point, the check, fills and focus rings. Orange words on white use #9A5300.
  2. The logo stays flat. Glass is for the interface around it. The mark is drawn solid so it holds at 16 pixels.
  3. Where the name appears. The mark in the header, the full logo once in the footer, the mark as the favicon.
