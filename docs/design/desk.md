# IssueSolved · the desk

Status: logo pass only (2026-11-02). Tokens, type, components and screens come after the mark is picked. No lock written yet, so the next run builds the full desk.

Mockup: https://claude.ai/artifact/5ACFTXmDtTxN6wtid1vqqX (`docs/design/desk.html`)

## Direction from the founder

- Clean white site. Three colors: black, white, and the orange from the current logo.
- A glass style for the interface.
- The name does not repeat across the page. A small mark carries the brand, the full name appears once.
- The brand is still being tested.

This reverses two decided items in the Core Identity note (black and white only, the old logo colors retired). The note needs an update before the site ships.

## Identity

| Color | Value | Use |
|---|---|---|
| Ink | `#111111` | Text, marks, tiles |
| White | `#FFFFFF` | Page background |
| Orange | `#FF9A00` | The point, the check, fills, focus rings. Never text on white (2.1:1). |
| Orange for text | `#9A5300` | Orange words on white (5.82:1) |

Wordmark face: Hanken Grotesk Medium, outlined (SIL Open Font License 1.1).

Directions, files in `docs/design/brand/options/`:

1. The point (recommended): lowercase `issuesolved`, the dot of the i is an orange point. Mark: the i on an ink tile.
2. The check: the old checkmark, redrawn square, orange on an ink tile, then `IssueSolved`.
3. The ring: an ink ring around an orange point, then `IssueSolved`.

Where the mark appears, three places: the header (mark only), the footer (full logo, once), the favicon (mark).

The logo stays flat. Glass belongs to the interface around it.
